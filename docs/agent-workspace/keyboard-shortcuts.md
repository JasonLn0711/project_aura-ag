# Agent Workspace Keyboard Shortcuts

| Shortcut | Action | Scope |
| --- | --- | --- |
| `Ctrl+N` | Create a new task | Agent Workspace |
| `Ctrl+K` | Open task and command search | Agent Workspace |
| `Enter` | Send when IME composition is inactive | Composer |
| `Shift+Enter` | Insert a newline | Composer |
| `Ctrl+Enter` / `Ctrl+Return` | Send explicitly | Composer |
| `Esc` | Close the active inspector, menu, or dialog | Current surface |
| `Tab` / `Shift+Tab` | Move through sidebar, thread, composer, approval, and inspector controls | Current surface |
| Arrow keys | Navigate repository/thread, category, candidate, and artifact lists | Focused list or tree |
| `Space` / `Enter` | Activate the focused button, context chip, or row action | Focused control |

Traditional Chinese IME composition owns Enter until the composition commit
finishes. The composer then applies the configured Enter-to-send behavior.
`Ctrl+Enter` remains the explicit send path.

Icon-only controls provide an accessible name and tooltip. Opening Evidence,
Environment, or Settings moves focus to the first useful control; closing the
surface returns focus to the invoking control.
